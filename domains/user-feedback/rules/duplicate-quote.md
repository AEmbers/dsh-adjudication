重复原话：两条不同的反馈 ID 记录了逐字相同的原话。要么是同一条被录了两次，要么是两条恰好措辞相同 —— 两种都需要判断，而按 ID 分开处理会重复计数影响面。取证义务：给出两个反馈 ID 与那段原话，并说明它们在其它字段（来源、日期、严重度）上是否也相同。不算：两条原话相同但来源渠道不同（一处应用商店、一处客服工单）—— 那是两个独立用户报了同一句话，是影响面的证据，不是重复。
